01Personal productData visualization

NFL Season Hub

NFL play-by-play data is public, excellent and almost unreadable. I built a way to see the shape of a game: six seasons, from the league table down to one play, in three clicks.

Role
Solo build: product, interface, data pipeline and tests
Built with
React 19, TypeScript, Vite, Canvas, Python (polars), Vitest, Playwright, Vercel
Decisions
  • Static JSON, no backend. A finished season never changes, so it ships as validated files on a CDN.
  • Canvas over React state. The replay cursor lives in a ref; React re-renders once per play, not 60 times a second.
  • A runtime data contract. Every file is checked field by field before the app sees it.

02ProductOperations platform

CNR Car Zone

A pre-owned vehicle business needed one place to track every car, from the first phone call to ready-for-sale. I built it as a mobile-first operations platform, and it is in production today.

Role
Sole engineer, designer and product owner
Built with
Next.js 15, Supabase, Postgres with row-level security, Netlify
Decisions
  • Staging split from production. A branch-based release, so nothing untested touches the owner's real data.
  • Backwards-compatible documents. Multi-image records shipped without migrating a single existing one by hand.
  • Private by design. CSV exports deliberately leave out seller ID and bank details.
